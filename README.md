# deutsch-reels

Сховище для Instagram-сторінки «Deutsch в зошиті» (@deutsch_v_zoshity).

- `reels/`: готові відео, які Metricool забирає за прямим посиланням raw.githubusercontent.com.
- `toolkit/reel/`: рендер рілса-квізу на 7 с (`render_reel.sh`).
- `PLAYBOOK.md`: повна інструкція автоматичного режиму (каруселі Пн/Ср/Пт 10:00, рілси Вт/Чт/Пт 14:00).
- `state.json`, `analytics_log.md`: поточний стан серії та журнал аналітики.
